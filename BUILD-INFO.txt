AMINE PS4 9.00 PRO LITE — STABILITY REVISION

Scope: firmware 9.00 only. Original exploit algorithms, offsets and binary payloads are preserved.
Stability changes in this revision:
- Fixed payload scheduling: the previous setTimeout(PayloadLoader(...), delay) form executed immediately and launched AIO and GoldHEN requests concurrently.
- Payload requests now validate non-empty responses and HTTP status, have a timeout, and report fetch/dispatch errors.
- AIO payload dispatch is awaited before GoldHEN dispatch, with a short settling delay between them.
- Corrected the offline cache manifest by removing a reference to a missing 900/background.jpg and listing the actual local runtime dependencies.
- Automatic retry/reload loops remain disabled to avoid repeated memory pressure.

Validation performed: JavaScript syntax check, local import/path checks, cache-manifest path checks, and ZIP CRC integrity.
Not verified: real PS4 browser execution, kernel exploit reliability, payload completion, or elimination of the browser's system-memory warning. The on-screen success state means the payload was dispatched, not independently verified as running.
